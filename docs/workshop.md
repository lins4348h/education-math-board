# 研習流程（約 90 分鐘）

給帶研習的講師參考。前提：老師已經安裝好 AI Agent，並有 GitHub 帳號。

| 時間 | 做什麼 | 重點 |
|------|--------|------|
| 0–15 分 | **先玩**：掃 QR 碼進解題館，每人玩一個內容包，故意拖錯幾張卡 | 讓老師先當學生，體會「錯卡就是誤解」 |
| 15–25 分 | **拆解**：打開「給老師」區塊，看回推八步驟與兩問檢驗 | 拖的是過程不是答案；誘答來自誤解規則 |
| 25–40 分 | **準備**：Fork 專案、開啟 GitHub Pages、確認 `node -v` | 照 `docs/github-pages.md` 一步一步做 |
| 40–75 分 | **動手**：用 Agent 打開專案，貼上入口頁的提示詞，做一個自己的內容包 | Agent 會先列出步驟和誤解請老師確認；這一關最花時間，也最有價值 |
| 75–90 分 | **發佈與分享**：驗算通過、建置、上傳，互相掃對方的 QR 碼試玩 | 打開 `test.html` 看「全部通過」 |

## 建議示範的單元

時間有限時，建議老師選步驟固定、誤解明確的單元：

- 八上 乘法公式：(a + b)² 展開，誤解「漏掉 2ab」「平方沒有分配到係數」
- 八上 因式分解：提公因式、十字交乘
- 七上 一元一次不等式：移項、乘以負數要變號

## 常見卡關

- **電腦沒有 Node.js**：到 https://nodejs.org 下載 LTS 版，安裝後重開 Agent。
- **Agent 一開始就寫程式**：提醒它「照 AGENTS.md，先整理步驟和誤解給我確認」。
- **驗算一直不過**：請 Agent 把錯誤訊息翻成白話說明；常見原因是卡片文字重複，或誘答卡剛好等於正解。
