# 內容包格式

一個內容包就是 `packs/` 裡的一個 `.js` 檔，最後呼叫 `SB.register(pack)`。最快的寫法：複製 `packs/_template.js`，再參考五個範例：

| 檔案 | 可以學什麼 |
|------|-----------|
| `01-paren.js` | 最標準的方程式步驟；共用的「係數化為 1」步驟 `divideStep` |
| `02-word1.js` | 應用題：多種題型隨機出、設未知數、列式、等價寫法（兩組 accept） |
| `03-elim.js` | 聯立方程式（兩行 stem）、一行裡有換行 `{ br: 1 }`、依條件出現的誘答卡 |
| `04-subst.js` | 代入時的括號誤解、去括號三種錯法 |
| `05-word2.js` | 兩個未知數的應用題、答案對調的診斷（兩格同時判斷） |

---

## pack 物件

| 欄位 | 說明 |
|------|------|
| `id` | 代號，小寫英文／數字／連字號，例如 `mult-formula`。網址 `#mult-formula` 直接進入。 |
| `grade` | 年級，例如 `八上`。入口頁依這個分組。 |
| `title` | 標題。 |
| `unit` | 單元名稱。 |
| `pitch` | 一句話介紹，顯示在入口頁卡片上。 |
| `kinds` | 誤解代碼 → 中文名稱。每個代碼都必須能被某條診斷規則觸發，否則驗算不會過。 |
| `stepLabels` | 步驟代碼 → 中文名稱。 |
| `make(rng)` | 產生一題。用 `makeWith('代號', (rng) => { … })` 包起來，回傳 `null` 會自動重新出題。 |

## make 回傳的題目

| 欄位 | 說明 |
|------|------|
| `stem` | 題目算式陣列。一行＝方程式（顯示「解方程式：…」）；兩行＝聯立方程式（顯示大括號，可在前面加 ①②）；應用題用 `[]`。 |
| `story` | 應用題的文字（可省略）。 |
| `params` | 產生這一題的參數，除錯用。 |
| `answer` | `{ x }` 或 `{ x, y }`；乘法公式、因式分解這類恆等式寫 `{ identity: true }`。 |
| `answerText` | 完成畫面顯示的答案，例如 `x = 3，y = −2`。 |
| `steps` | 步驟陣列，每一個用 `buildStep(spec, rng)` 產生。 |

## buildStep 的 spec

| 欄位 | 說明 |
|------|------|
| `key` | 步驟代碼，要寫在 `stepLabels`。 |
| `goal` | 這一步要做什麼，顯示在右側。 |
| `scaffold` | （可省略）鷹架文字，例如「代入 ①：3 × (−2) + 2y = 4」。 |
| `line` | 算式行。陣列元素可以是：字串（固定文字）、`{ slot: 'a' }`（空格）、`{ frac: [[分子…], [分母…]] }`（分數）、`{ br: 1 }`（換行）。**空格 1～3 個。** |
| `cards` | 卡片：`{ key, text }`；誘答卡多一個 `trap: '誤解代碼'`。條件不成立的卡片寫 `false`，會被自動略過。卡片文字不能重複，卡片至少比空格多 1 張。 |
| `accept` | 可接受的放法陣列，例如 `[{ l: 'ok1', r: 'ok2' }]`。等價寫法（左右對調等）就多列一組。 |
| `diagnose` | 診斷規則：`{ when: { 空格: '卡片 key' 或 ['key1', 'key2'] }, kind: '誤解代碼', fb: '回饋句' }`。由上往下比對，第一條符合的生效。每張誘答卡都要有對應規則。 |
| `hints` | **剛好三層**：方向 → 關鍵關係 → 幾乎給出一格。學生用到第三層時，畫面會標出一個空格該放哪張卡。 |
| `fallback` | （可省略）不符合任何診斷規則時的回饋。 |

`buildStep` 會打亂卡片順序並換成中性的代號（c1、c2…），學生無法從網頁原始碼看出哪張是正解。卡片文字重複時回傳 `null`，`makeWith` 會自動重新出題。

## 寫字的規則

- 負號一律用「−」（U+2212），請用工具 `num()`、`sg()` 產生，不要自己打 `-`。
- 乘號 `×`、除號 `÷`；分數在卡片裡寫 `[frac:分子|分母]`，或用工具 `fracText(n, d)`。
- 平方寫 `x²`（上標字元），或用 `^2`。
- `x`、`y` 會自動用斜體數學字型顯示。

## 自動驗算怎麼檢查

`node test/run.mjs` 會產生 1500 題，每一題：

1. 把**正解卡**放進每一行，組成整行文字，切成片段（以「，」「：」「；」「得」「答」和全形空白切開），只含數字、x、y、運算符號的片段才拿來求值。
2. 把答案代入（恆等式則代入好幾組數字），等號兩邊必須相等。
3. 檢查格式：空格數、卡片數、卡片不重複、三層提示、每張誘答卡都有診斷規則、每條規則都會觸發自己的誤解代碼、每個 `kinds` 都至少被觸發一次。
4. 每一題至少要有一行可以求值，否則視為沒有驗算。

因此，像「設 每枝原子筆 x 元」這種中文行不會被驗算，但下一步的「7x + 60 = 172」一定會被代回答案檢查。

## 工具（`SB.tools`）

| 工具 | 用途 | 例子 |
|------|------|------|
| `makeWith(name, fn)` | 包住出題函式，回傳 null 自動重出 | — |
| `buildStep(spec, rng)` | 建立一個步驟 | — |
| `divideStep(rng, { A, K, x, wrongCoef, label })` | 共用的「x = K/A = x」步驟 | 見 `01-paren.js` |
| `rnd(rng, lo, hi)` | 整數亂數 | `rnd(rng, 2, 9)` |
| `nz(rng, lo, hi)` | 不為 0 的整數亂數 | `nz(rng, -6, 6)` |
| `pick(rng, 陣列)` | 隨機挑一個 | `pick(rng, [2, 3])` |
| `gcd(a, b)` | 最大公因數 | — |
| `num(n)` | 數字，負號用 − | `num(-3)` → `−3` |
| `sg(n)` | 帶正負號的數 | `sg(3)` → `+3` |
| `pn(n)` | 負數加括號 | `pn(-3)` → `(−3)` |
| `op(n)` | 算式中的「＋ 3」「− 3」 | `op(-3)` → `− 3` |
| `term(c, 'x', signed)` | 單項式 | `term(-1, 'x')` → `−x`；`term(3, 'x', true)` → `+3x` |
| `lin([[c, 'x'], [k, '']])` | 多項式 | `lin([[2, 'x'], [-5, '']])` → `2x − 5` |
| `eqXY(a, b, c)` | 二元一次方程式 | `eqXY(3, -2, 7)` → `3x − 2y = 7` |
| `fracText(n, d)` | 分數卡片文字 | `fracText(1, -3)` → 負三分之一 |
